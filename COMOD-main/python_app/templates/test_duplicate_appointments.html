Prueba de Restricción de Turnos Duplicados

Esta página permite probar la funcionalidad de restricción de turnos duplicados.

Funcionalidad Implementada:
  • Validación de duplicados: No se pueden crear turnos con la misma fecha, hora y odontólogo
  • Validación de fecha: No se pueden programar turnos en fechas pasadas
  • Validación de hora: No se pueden programar turnos en horarios pasados
  • Mensajes específicos: Notificaciones claras sobre el tipo de conflicto
  • Exclusión de cancelados: Los turnos cancelados no bloquean nuevos turnos
